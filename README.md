# PicoMint OS

PicoMint OS is a lightweight, modular MicroPython graphical interface for the Raspberry Pi Pico 2W. It is made to run on a 128x64 I2C OLED display driven by an SH1106 chip, but can really run on any I2C display with enough tinkering.

## What are its features?

It wasn't made to come with a bunch of stuff, so it just includes some basics:
- Modular menu system
- App examples, such as Snake and Terminal
- Wi-Fi and Bluetooth menus
- An idle screen with a little fox

Remember that the entire project is modular, so you can easily make your own apps, menus, and more!

## How do I run it?

Just download this repository, drop it onto your Pico (make sure main.py is in the root directory), and you're good to go!# picomint-os
